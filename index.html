My Projects

Project 1: Tala

A daily reading app that turns a person's birth chart into a simple, friendly overview of their day. I contribute to its documentation and marketing pages, working with a team through GitHub branches and pull requests.

Project 2: Reserve, a Discussion Room Reservation App

A booking system for school discussion rooms with separate views for students, faculty and admins. It walks users through a four-step booking wizard and gives admins a queue for approving requests and settling schedule conflicts.

Project 3: Lumen Glasses

A landing page for a concept pair of smart glasses. Visitors can spin a 3D model of the frame, pick from three finishes, explore the hardware and features like live translation and hands-free navigation, and pre-order. View the live site.

Project 4: Wavelength

An ambient focus studio in the browser. You mix layers of calming background sound to build your own atmosphere, then start a focus session to get work done. All the sound is generated live in the browser with the Web Audio API, so there are no audio files to download. Try it live.
